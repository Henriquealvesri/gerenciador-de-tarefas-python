## Gerenciador de Tarefas em Python

Sistema de gerenciamento de tarefas desenvolvido com Python e SQLite.

## Funcionalidades

- Cadastro de usuários
- Login com senha criptografada (SHA-256)
- Adição de tarefas
- Remoção de tarefas
- Marcação de tarefas concluídas
- Prioridades
- Categorias
- Datas de vencimento
- Estatísticas

## Tecnologias

- Python 3.15
- SQLite
- SQL
- Hashlib
- Git
- GitHub

## Como executar

```bash
python main.py
